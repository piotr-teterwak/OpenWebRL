About smoothing

W&B EMA uses the documented bias correction: previous observations decay by the selected weight, then the weighted sum is divided by the accumulated weights. This is W&B’s EMA option, not its default time-weighted EMA. Gaussian uses a normalized Gaussian kernel over training-iteration distance, including earlier and later checkpoints; σ is measured in iterations. Try σ = 10 for roughly one checkpoint interval. Both methods average only observed values and leave raw results unchanged. W&B smoothing reference ↗

The raw faint trace plus stronger trend follows the presentation in OpenWebRL Figure 2(c) ↗; the authors’ exact smoothing algorithm and parameter are unverified.
